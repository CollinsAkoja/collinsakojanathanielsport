My Journey

From Beginner to Builder

A timeline of my growth, learning milestones, and key moments in my tech career.

2021 — The Beginning

First Steps Into Coding

Discovered my passion for technology at Earlycode Computer Schools. Wrote my first "Hello World" in HTML and knew I had found my calling. Started with basic web pages and fell in love with the creative possibilities of code.

2022 — Leveling Up

Mastering the Fundamentals

Deep-dived into JavaScript, CSS animations, and responsive design. Built my first interactive projects and started contributing to open source on GitHub. Learned Git version control and collaborative development workflows.

2023 — Backend & AI

Expanding Into Python & Django

Transitioned into backend development with Python and Django. Built full-stack applications with MySQL databases. Simultaneously began exploring AI and machine learning, taking courses and building predictive models.

2024 — Professional Growth

Industry Associations & Real Projects

Joined FLEXISAF, UNITAR, and disasterready.org as an associate. Started freelancing on Upwork and Fiverr. Delivered real-world projects for clients and built a growing portfolio of production applications.

2025 — Present

Full-Stack Developer & AI Enthusiast

Now working as a full-stack developer combining web development with AI/ML solutions. Continuously learning, building, and sharing knowledge through my blog and GitHub. Focused on creating technology that makes a difference.
